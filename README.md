
# AI-ImageGenX

AI-ImageGenX is a web application that leverages artificial intelligence to convert text prompts into images. Utilizing the MERN stack, it provides users with a seamless experience to generate and share AI-created visuals.

## 🌟 Features

- **Text-to-Image Generation**: Input descriptive text to produce corresponding images using AI models.
- **Community Sharing**: Share your creations with others and explore images generated by the community.
- **Responsive Design**: Enjoy a user-friendly interface optimized for various devices.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **AI Integration**: OpenAI's DALL·E API
- **Image Hosting**: Cloudinary

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:

- Node.js
- npm
- MongoDB

### Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/AnanyaShriv/-AI-ImageGenX.git
   cd -AI-ImageGenX
2. Install dependencies:
cd client
npm install
cd ../server
npm install
3. Configure environment variables:

Create a .env file in both the client and server directories based on the provided .env.sample files. Populate them with your configuration details, including API keys and database URIs.

4. Run the application:

# In the client directory

# In the server directory
npm start
